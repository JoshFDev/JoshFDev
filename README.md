## Sobre mí

Estudiante de Ingeniería en Computación enfocado en el desarrollo **backend**. Me interesa el ciclo completo detrás de una aplicación: diseño de APIs, modelado de bases de datos, lógica de negocio y buenas prácticas de arquitectura de software.

- Trabajo del lado del servidor con **Java, C# y JavaScript/TypeScript**.
- Construyo APIs REST con **Spring Boot**, **Node.js + Express** y **.NET**.
- Conozco el ecosistema Java a fondo: **Spring** y **JavaServer Faces (JSF)**.
- Uso **React, Next.js, Angular y Bootstrap** para integrar y consumir servicios de punta a punta.
- Profundizo en **bases de datos relacionales y no relacionales**.
- Mi meta: convertirme en un desarrollador backend sólido, aprendiendo de forma constante.
